Metric display. `tile` for 3-up grids inside a section; `proof` for the credibility band under the hero.

```jsx
<StatTile value="$2.5B+" label="Swapped natively — no bridges" variant="proof" />
<StatTile value="172" label="Countries served" />
```

Proof values render in the Signal gradient; tile values are plain white tabular numerals.
